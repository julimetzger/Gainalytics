## Play Console inputs (proposed)

**Data safety.** No developer server, no analytics/crash SDK, no ads. Data leaves the device only to
the AI provider the user configures, encrypted in transit (HTTPS).

| Play data type | Sent off device | Purpose | Optional |
|---|---|---|---|
| Health & fitness → Fitness info (exercises, sets, weights, reps, RIR, plans, durations, video-analysis metrics) | To Anthropic/OpenAI when AI chat, coach insight or "Plan with AI" is used | App functionality | Yes (AI is opt-in) |
| Health & fitness → Health info (sleep duration/stages, daily steps) | Only with "Include sleep and steps" in the AI chat | App functionality | Yes |
| Messages / other user-generated content (chat prompts) | To the AI provider | App functionality | Yes |
| Device or other IDs (random per-install `ext_agent_host_id`) | To OpenAI during ChatGPT sign-in | App functionality | Yes |
| Body weight (Health Connect), videos | Not sent; shown/processed on device | – | – |

Deletion: all data is stored on the device and deleted by the user (uninstall, in-app delete,
ChatGPT sign-out removes tokens, `chatgptSession.ts:177`). **Account deletion: not applicable** — the
app has no accounts; ChatGPT sign-in uses the user's own OpenAI account.

**Health Connect declaration** (use case: fitness / coaching):

| Permission | Feature | Justification |
|---|---|---|
| READ_EXERCISE / WRITE_EXERCISE | Write finished trainings; read back only own records | Sync strength trainings to Health Connect |
| READ_WEIGHT | Analysis: current weight, trend, relative strength | Display only, not stored |
| READ_HEALTH_DATA_HISTORY | Weight history older than 30 days | Long-term analysis |
| READ_SLEEP / READ_STEPS (new) | Recovery context in the AI chat, opt-in toggle | Read only when enabled; sent to the user's AI provider, previewable in "View context" |

**Other declarations:** exact alarm — `SCHEDULE_EXACT_ALARM` is user-granted, no Play declaration
(only `USE_EXACT_ALARM` is restricted); foreground services — declare `dataSync` for video analysis
and ChatGPT sign-in with a short video each (see S4); Photo/Video permissions — none requested (GH-421).

## Checked and OK

- **Cleartext/network:** no `usesCleartextTraffic` in the main or release manifest (only `src/debug/AndroidManifest.xml:16`), no `networkSecurityConfig`; app code talks only to `https://` hosts (`api.anthropic.com`, `auth.openai.com`, `api.openai.com`, `chatgpt.com`); the only `http://` is the OAuth loopback redirect.
- **OAuth loopback:** listener bound to `127.0.0.1` only (`ChatGptLoopbackModule.kt:70`), PKCE S256 with `SecureRandom`, `state` checked (`chatgptAuth.ts:87`), tokens in the encrypted store, sign-out removes them.
- **Secrets not logged:** logs only print lengths/flags (`sendChatMessage.ts:62`, `AIChatTab.tsx:383`); Toasts say "API key saved/removed/valid"; native `Log.*` calls (8) carry no secrets.
- **Debug tooling off in release:** `redux-logger` and Redux devtools only with `NODE_ENV === 'development'` (`configureStore.ts:217-221`); `LogBox.ignoreAllLogs` only under `__DEV__` (`index.tsx:27`); release manifest not debuggable.
- **Debug-only code:** `HealthConnectTestDataActivity`, `WRITE_WEIGHT/SLEEP/STEPS` and `SYSTEM_ALERT_WINDOW` exist only in `src/debug`; none of them is in the 0.188 release manifest.
- **Exported components:** `MainActivity` (launcher + `gainalytics://chatgpt-signin`, no data parsed), Health Connect rationale (static bundled policy, JS disabled), alias protected by `START_VIEW_PERMISSION_USAGE`; library components (WorkManager, profileinstaller, notifee, Health Connect SDK service) are standard or permission-protected.
- **FileProvider:** only `cache/exports/` (`file_share_paths.xml`), `PendingIntent.FLAG_IMMUTABLE` (`FileShareModule.kt:56`). Downloads via MediaStore without a storage permission.
- **Media permissions:** no `READ_MEDIA_*`; videos via `ACTION_OPEN_DOCUMENT` (GH-421).
- **Backup:** `allowBackup="false"`; Health Connect values are held in memory only (`configureStore.ts:197-199`).
- **Target/compile SDK 36:** meets Play's API 36 requirement (deadline 2026-08-31, extension 2026-11-01).
- **16 KB page size, arm64-v8a:** all libs `0x4000`; all `.so` stored uncompressed and 16 KB zip-aligned (`extractNativeLibs=false`); own CMake library gets `ANDROID_SUPPORT_FLEXIBLE_PAGE_SIZES=ON` from the RN Gradle plugin. Only x86_64 TFLite fails (S1).
- **Release pipeline:** signing key only from the tag-restricted `release` environment, certificate pinning check, least-privilege workflow permissions, actions pinned by SHA; agent workflows check the actor.
- **Repository:** no secrets in tracked files (pattern scan; only the standard `debug.keystore`); secret scanning and private vulnerability reporting are on; `SECURITY.md` exists.
- **Privacy policy (Health Connect part):** per-type description, opt-in, revocation, no ads/sale; the bundled asset equals `index.html`.
