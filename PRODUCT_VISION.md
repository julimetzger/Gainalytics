# Gainalytics – Product Vision

This file describes the long-term vision and feature roadmap.
This is NOT binding for implementation unless explicitly requested.

---

# Vision

Gainalytics is a privacy-first, offline-first training analytics app for advanced lifters.

Slogan:

Log your gains with Gainalytics.
The powerful app for power users — privacy-and-local-first, open, flexible.

Core principles:

- Privacy-first
- Offline-first
- Open and extensible
- No required cloud
- User owns their data

---

# Core Feature Areas

## Training Logging

Flexible logging:

- custom exercises
- sets, reps, weight
- RIR / RPE
- rest time

Session tagging:

- Push, Pull, Legs, Upper, Lower, Mobility

---

## Analytics

Volume, sets, reps, 1RM records, 1RM analytics:

- per exercise
- per muscle group
- per week
- per micro

Intensity analytics:

- average RPE
- average RIR
- fatigue trends

Visualizations:

- line charts
- bar charts
- scatter plots
- heatmaps

Comparisons:

- compare micros
- compare exercises
- compare time ranges
